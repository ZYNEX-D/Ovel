# FORMA — built site

Production build of the FORMA architecture site, served by jsDelivr:
`https://cdn.jsdelivr.net/gh/souranyp-stack/forma-site@v1.1.0/`

`index.html` here is the page hosted on Aura; every script, stylesheet, image and model it loads comes from this tag.
Built with `CDN_BASE=https://cdn.jsdelivr.net/gh/souranyp-stack/forma-site@v1.1.0/ npm run build:cdn`.
